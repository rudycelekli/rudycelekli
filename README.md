## I build AI systems that can prove what happened.

I am **Rudy Mizrahi Celekli**, also known professionally as **Rudy Celekli**. My work focuses on verifiable long-horizon agent environments, evaluator robustness, deterministic replay, causal fault isolation, and evidence-bound execution.

The operating principle is simple: preserve the world state, replay the action, challenge the evaluator, isolate the failure, and retain enough evidence for another person to check the claim. Public ownership, upstream contribution, measured results, and exploratory work stay explicitly separate.

## Operating principles

```text
Direct       goals, constraints, acceptance criteria, escalation
Orchestrate  models, agents, tools, memory, and bounded loops
Verify       receipts, replay, tests, independent challenge
Improve      measured failure becomes a better next run
```

- **Can we trust the record?** Proof-bound execution evidence.
- **Can we trust the score?** Adversarial evaluator stress testing.
- **Can we reproduce the result?** Deterministic replay and committed artifacts.
- **Can an agent remember?** Regression memory before another change reaches history.

The standard is not that an AI system sounds convincing. It is that the system can show its work without asking you to trust the system.
