## I build AI systems that can prove what happened.

**On a mission to make open source reliable enough to trust. One repository at a time.**

I am **Rudy Mizrahi Celekli**, also known professionally as **Rudy Celekli**. I research and build long-horizon agent systems, evaluation environments, and evidence-bound execution, with a focus on evaluator robustness, deterministic replay, and causal fault isolation.

The work has two connected fronts: building AI systems whose behavior can be inspected, and strengthening the open-source foundations those systems rely on.

Open source is shared infrastructure. A silent data error, a misleading evaluation, or an agent that fails without a useful trace can become someone else's production problem.

I work on those failure points: reproduce the problem, fix the cause, add a regression test, and get the change accepted upstream. Reliability and correctness are foundations of trust and safety.

An accepted fix improves a shared dependency. A regression test helps maintainers keep that failure from returning. My goal is fewer inherited failures and software people can depend on.

Research, owned products, upstream contributions, and measured results remain explicitly separate.

HEH is estimated task-equivalent effort: PR-title categories and change statistics for accepted upstream work, and conventional-title classes for owned default-branch commits. Authorship dates are attribution evidence, not a timesheet. Owned default-branch presence is an acceptance proxy, not independent maintainer review. These models do not establish measured labor, time saved, or downstream impact.

Reuse excluded: 555 repeated public-PR commit entries and 0 owned commits already covered by PR work. The first accepted PR receives implementation credit; later PR estimates count only the proportion of newly credited implementation commits, with no additional integration-effort estimate.

The 12-month AP is total modeled HEH divided by total assumed direction hours, not an average of the monthly multipliers. When coverage is incomplete, the aggregate is labeled recorded-work only, not an account-wide total. The model rolls forward automatically; new activity does not rescale other months. Historical evidence corrections and later acceptance can revise the affected work months.

Private repository names, raw commit SHAs, exact dates, URLs, code, and commit text stay private. One-way commit digests support deduplication against public PRs. The scope is personally owned non-fork repositories plus public upstream contributions; employer/client organization repositories, forks, the profile repository, and explicit authorship exceptions are excluded.

## Operating principles

```text
Direct       goals, constraints, acceptance criteria, escalation
Orchestrate  models, agents, tools, memory, and bounded loops
Verify       receipts, replay, tests, independent challenge
Improve      measured failure becomes a better next run
```

- **Can we trust the record?** Proof-bound execution evidence.
- **Can we trust the score?** Adversarial evaluator stress testing.
- **Can we reproduce the result?** Deterministic replay and committed artifacts.
- **Can an agent remember?** Regression memory before another change reaches history.

The standard is not that an AI system sounds convincing. It is that the system can show its work without asking you to trust the system.
